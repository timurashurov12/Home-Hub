# TV Hub

Локальная панель для управления любыми Android-приставками и телевизорами в домашней сети через ADB: Android TV, Google TV, Fire TV, Xiaomi Mi Box / Mi TV Stick, Nvidia Shield, Chromecast with Google TV и т.д.

**Стек:** NestJS 11 (сервер, вызывает `adb`) + React 19 / Vite (веб-интерфейс). Панель открывается в браузере, в том числе с телефона в той же Wi‑Fi сети.

## Что умеет

- **Сканер сети при запуске:** ищет устройства по ADB (5555), сервису пульта Android TV (6466) и Google Cast (8009/mDNS), показывает имя и модель; новые можно добавить по одному или все сразу. Устройства с закрытым ADB тоже видны, с подсказкой включить отладку. Отключается в окне сканера или `AUTO_SCAN=false`
- Ручное добавление по `IP:порт`
- Сохранённый список ТВ с названиями, статусом (в сети / не в сети / ждёт подтверждения) и **автопереподключением** каждые 30 с
- **Информация:** модель, Android, сборка, разрешение, IP, аптайм, RAM и хранилище
- **Установка APK:** загрузка файла (drag&drop) или по ссылке, **сразу на несколько ТВ**
- **Приложения:** список (свои и системные), поиск, запуск, остановка, очистка данных, отключение/включение, удаление
- **Удаление предустановленных приложений без root:** вкладка «Предустановленные» с метками «можно удалить» / «осторожно» / «не трогать», массовое удаление, вкладка «Удалённые» с восстановлением
- **Пульт:** D‑pad, OK, назад, домой, меню, громкость, медиакнопки, питание; управление с клавиатуры компьютера; ввод текста; открыть ссылку на ТВ
- **Скриншот экрана** (с автообновлением и скачиванием), перезагрузка, сон/пробуждение

## Требования

Для запуска без Docker:

1. **Node.js 20+**
2. **adb** (Android SDK Platform‑Tools): https://developer.android.com/tools/releases/platform-tools
   - macOS: `brew install android-platform-tools`
   - Windows: `winget install Google.PlatformTools` (или скачать zip и добавить в PATH)
   - Linux: `sudo apt install adb`
   Если `adb` не в PATH, укажи путь: `ADB_PATH=/path/to/adb`.

## Настройка приставки (один раз на каждой)

Ниже шаги для Android TV / Google TV (Mi TV Stick, Mi Box и т.п.). На Fire TV: Настройки → Моё устройство Fire TV → Параметры разработчика → Отладка ADB.

1. **Настройки → Настройки устройства → Об устройстве** → 7 раз нажми на **«Сборка»**, появится «Вы стали разработчиком».
2. **Настройки устройства → Для разработчиков** → включи **«Отладка по USB»** (на стиках она работает и по сети).
   Если есть пункт **«Отладка по сети» / «ADB over network»**, включи и его.
3. Узнай IP стика: **Настройки → Сеть и Интернет → твоя Wi‑Fi сеть**. Удобно закрепить IP за стиком в настройках роутера (DHCP reservation).
4. При первом подключении из TV Hub на экране ТВ появится **«Разрешить отладку?»**: отметь «Всегда разрешать с этого компьютера» и нажми ОК.

> Если порт 5555 закрыт (бывает на Android 11+ после перезагрузки), один раз подключи стик по USB к компьютеру и выполни `adb tcpip 5555`.

## Запуск в Docker (рекомендуется)

`adb` уже внутри образа, ставить на компьютер ничего не нужно, кроме Docker.

**Linux** (host-сеть, работает автопоиск и mDNS):

```bash
cp .env.example .env   # при желании поменяй TVHUB_PORT
docker compose up -d --build
# панель: http://localhost:8765 или http://<IP компьютера>:8765
```

**macOS / Windows (Docker Desktop):** контейнер в bridge-сети не видит домашнюю подсеть сам, поэтому её нужно указать:

```bash
cp .env.example .env   # раскомментируй SCAN_SUBNETS и впиши свою подсеть, напр. 192.168.1.0
docker compose -f docker-compose.bridge.yml up -d --build
```

> В Docker Desktop 4.34+ можно включить host-сеть (Settings → Resources → Network → Enable host networking) и использовать обычный `docker-compose.yml`.

Данные хранятся в томах: `tv-hub-data` (список ТВ) и `tv-hub-adb-keys` (ключ adb, чтобы ТВ не спрашивал разрешение после пересоздания контейнера).
Логи: `docker compose logs -f`. Обновление: `git pull && docker compose up -d --build`.

## Запуск на macOS без Docker (если сканер в Docker ничего не находит)

Docker Desktop на Mac держит контейнер в отдельной виртуальной сети, а macOS 15+ может не пускать Docker в локальную сеть. Без Docker этих проблем нет:

Проще всего без терминала: открой папку проекта в Finder и дважды кликни **Start TV Hub.command** (при первом запуске: правый клик → Открыть). Панель откроется в браузере сама. Перед этим останови контейнер в Docker Desktop, если он запущен.

Или из терминала:

```bash
docker compose -f docker-compose.bridge.yml down   # если контейнер запущен
./scripts/start-mac.sh                              # поставит adb и node через Homebrew, соберёт и запустит
# панель: http://localhost:8765
```

## Запуск без Docker

```bash
npm install

# режим разработки: сервер на :8765, интерфейс на http://localhost:5173
npm run dev

# продакшн: собрать и запустить всё на одном порту http://localhost:8765
npm run build
npm start
```

Переменные окружения сервера: `PORT` (8765; в Docker задаётся через `TVHUB_PORT` в `.env`), `HOST` (0.0.0.0), `ADB_PATH`, `DATA_DIR` (папка для `devices.json`, по умолчанию `./data`), `SCAN_SUBNETS` (подсети для поиска через запятую, напр. `192.168.1.0,192.168.0.0`; по умолчанию подсети сетевых интерфейсов), `SCAN_TIMEOUT_MS` (таймаут проверки порта, 800), `AUTO_SCAN` (`false` отключает скан при запуске сервера).

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/devices` | список ТВ со статусом |
| POST | `/api/devices` `{host, port?, name?}` | подключить и сохранить |
| PATCH / DELETE | `/api/devices/:id` | переименовать / удалить |
| POST | `/api/devices/:id/connect` | переподключить |
| POST | `/api/discovery/scan` `{subnet?}` | поиск в сети |
| GET | `/api/discovery/last` | результат последнего скана (в т.ч. автоскана) |
| GET | `/api/devices/:id/info` | информация об устройстве |
| GET | `/api/devices/:id/apps?system=true` | приложения |
| POST | `/api/devices/:id/apps/:pkg/(launch\|stop\|clear\|disable\|enable\|uninstall)` | действия с приложением |
| POST | `/api/install` multipart `apk`, `deviceIds=a,b` | установка APK на несколько ТВ |
| POST | `/api/install-url` `{url, deviceIds[]}` | установка по ссылке |
| POST | `/api/devices/:id/key` `{key}` | кнопка пульта (`up`, `ok`, `home`, `volume_up`… или числовой KEYCODE) |
| POST | `/api/devices/:id/text` `{text}` | ввод текста |
| POST | `/api/devices/:id/open-url` `{url}` | открыть ссылку |
| GET | `/api/devices/:id/screenshot` | PNG экрана |
| POST | `/api/devices/:id/reboot` | перезагрузка |

`:id` это `IP:порт`, в URL кодируется (`192.168.1.50%3A5555`).

## Обновления приложений

Вкладка «Приложения» → «Обновления» сравнивает установленные версии с последними релизами:

- **GitHub** — для популярных приложений Android TV источник известен заранее (SmartTube, Jellyfin, mpv, NewPipe, LibreTube, Termux, LocalSend). Для любого другого приложения можно указать репозиторий `owner/repo` и, если в релизе несколько APK, шаблон имени файла. APK выбирается под архитектуру приставки (`ro.product.cpu.abilist`).
- **F-Droid** — проверяется автоматически для любого установленного приложения.

Обновление — одной кнопкой или «Обновить всё». Если новая версия подписана другим ключом (приложение ставили из другого источника), Android откажет в установке, панель это объяснит. Ответы GitHub кешируются в Redis на час; без `GITHUB_TOKEN` GitHub разрешает 60 запросов в час. APKMirror не поддерживается: у него нет API и он закрыт от автоматических запросов. Приложения из Google Play обновляет сам Play Маркет.

## Файлы и видео

Вкладка «Файлы и видео»:

- **Видео по ссылке** — прямая ссылка (.mp4, .mkv, .m3u8…), YouTube или любая ссылка открывается на ТВ в выбранном плеере (список плееров берётся с приставки).
- **Файлы** — просмотр `/sdcard` и подключённых флешек, загрузка с компьютера (кнопкой или перетаскиванием), скачивание на компьютер, создание папок, удаление. Видео, музыку и картинки можно сразу открыть на ТВ. Системные разделы недоступны.

## Блокировка рекламы

Вкладка «Обзор» → «Блокировка рекламы» включает системный Private DNS (DNS-over-TLS, Android 9+): реклама и трекеры блокируются во всех приложениях и на главном экране, без root и VPN. Провайдеры: AdGuard DNS (по умолчанию, бесплатный), AdGuard «Семейный», NextDNS (нужен свой ID) или свой сервер. Можно применить к одному ТВ или ко всем онлайн-ТВ сразу. После включения панель проверяет, что интернет на ТВ работает; если сервер не отвечает, прежние настройки возвращаются автоматически. «Выключить» восстанавливает исходные значения `private_dns_mode` и `private_dns_specifier`.

Рекламу YouTube DNS не убирает: она приходит с тех же серверов, что и видео.

## Кеш мониторинга (Redis)

Docker Compose поднимает рядом контейнер `tv-hub-redis` (redis:7-alpine, до 64 МБ). В нём хранятся:

- последний снимок `/stats` каждого ТВ. Ответ всегда идёт из кеша сразу; если снимок старше 4 с (`STATS_CACHE_MS`), он обновляется в фоне. Раз в минуту (`STATS_BG_INTERVAL_MS`, 0 — выключить) сервер сам собирает данные со всех онлайн-ТВ, поэтому вкладка «Мониторинг» открывается мгновенно. `?fresh=1` ждёт свежие данные в обход кеша;
- история CPU, памяти и температуры за последний час (`GET /api/devices/:id/stats/history`), поэтому график не обнуляется при перезагрузке страницы или контейнера.

Без Redis (`REDIS_URL` не задан или Redis недоступен) приложение работает с кешем в памяти. Текущий режим видно в `GET /api/health` (`cache: redis | memory`).

## Удаление предустановленных приложений

Системные пакеты удаляются командой `pm uninstall -k --user 0 <пакет>`: root не нужен, APK остаётся в системном разделе, поэтому любое приложение можно вернуть (`cmd package install-existing`) во вкладке «Удалённые» или сбросом до заводских настроек.

Метки берутся из справочника `server/src/devices/catalog.ts`:
- **можно удалить**: Play Игры, Play Фильмы, YouTube Music, заставки, TalkBack, предустановленные стриминги и т.п.
- **осторожно**: Play Маркет, Ассистент (кнопка микрофона), Chromecast built-in, WebView, рекомендации
- **не трогать**: лаунчер, системный интерфейс, Bluetooth (пульт), сервисы Google Play, клавиатура, `com.android.shell` (без него ADB перестанет работать). Удалить их можно только после ввода имени пакета.

Пакеты без метки справочнику неизвестны (часто это сервисы производителя): удаляй их по одному и проверяй, что стик работает. Справочник легко дополнять.

## Если сканер ничего не находит

1. В окне сканера есть «Проверить IP»: покажет по каждому порту, открыт он, закрыт или устройство не отвечает. Если сервер не видит даже роутер, сканер прямо об этом напишет.
1. В окне сканера видно, какие подсети проверялись. Если там `172.x`, это внутренняя сеть Docker: укажи домашнюю подсеть в `SCAN_SUBNETS`.
2. macOS 15+: Системные настройки → Конфиденциальность и безопасность → Локальная сеть → включи Docker.
3. Проверь доступность ТВ с компьютера: `nc -vz <IP_ТВ> 8009` (Google Cast открыт на любом Android TV) и `nc -vz <IP_ТВ> 5555` (ADB).
4. ТВ должен быть включён (не в глубоком сне) и в той же сети, не в гостевой Wi‑Fi.

## Безопасность

ADB даёт полный доступ к стику. Панель слушает `0.0.0.0` без авторизации: запускай её только в доверенной домашней сети или поставь `HOST=127.0.0.1`.
